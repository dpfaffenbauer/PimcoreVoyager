# Assets Placeholder

This directory will contain app assets like:

- `icon.png` - App icon (1024x1024)
- `splash.png` - Splash screen
- `adaptive-icon.png` - Android adaptive icon (1024x1024)
- `favicon.png` - Web favicon

## Generating Assets

Use the Expo icon generator or create manually:

```bash
# Generate all sizes automatically
npx expo-app-icon-generator
```

## Required Sizes

### icon.png
- Size: 1024x1024
- Format: PNG with transparency

### splash.png
- Size: Minimum 2048x2048
- Format: PNG
- Safe area: Center 1284x2778 for content

### adaptive-icon.png (Android)
- Size: 1024x1024
- Format: PNG with transparency
- Safe area: Center circle with 66% diameter

### favicon.png (Web)
- Size: 48x48 or higher
- Format: PNG

## Placeholder Assets

For development, you can use solid color placeholders until final assets are ready.
